# 대통령 홈페이지 시안

한 Next.js 프로젝트에서 `/a`, `/b`, `/c`를 제공합니다. 각 경로 아래 `/menu`, `/lunch`, `/about`, `/location`이 독립적으로 열립니다. `/`는 비교 화면입니다. 시안 전환 시 현재 하위 페이지를 유지합니다. 잘못된 시안과 하위 경로는 404입니다.

- A: 용스 다이닝에서 참고한 큰 사진과 붉은 포인트.
- B: 짙은 녹색, 분할형 메인, 아치형 사진.
- C: 밝은 노란색, 포스터형 구성, 방문 정보.

공통 사실 정보: `data/restaurant.ts`, `data/links.ts`. 메뉴와 점심 메뉴: `data/menu.ts`, `data/lunch.ts`. 2026-10-14 수집 자료의 유료 메뉴 32개와 점심 메뉴 3개를 공통 데이터에 반영했습니다. 콜키지 무료 안내는 별도로 표시합니다. 사진: 기존 제공 자산을 `public/images/proposals`에 영문 파일명으로 복사했습니다.

기존 `/menu`, `/lunch`, `/about`, `/location`은 `(original)` 라우트 그룹으로 유지했습니다. 시안 페이지는 검색 색인을 비활성화했습니다.

Vercel에서는 이 레포 하나를 Next.js 프로젝트로 연결하면 됩니다. 별도의 rewrite나 프로젝트 3개가 필요하지 않습니다. 선택 후 루트 홈페이지와 검색 메타데이터를 최종안 기준으로 전환하세요.

점심 전용 내비게이션은 제거했습니다. 점심 메뉴는 메뉴 페이지의 식사 분류에 포함됩니다. 기존 `/a/lunch`, `/b/lunch`, `/c/lunch`는 각 시안의 `/menu`로, `/lunch`는 `/menu`로 연결됩니다.
